# Local AI Chat • Ollama

โปรแกรมแชตกับโมเดล AI ในเครื่องผ่าน [Ollama](https://ollama.com) เขียนด้วย Python + tkinter
ใช้แค่ไลบรารีมาตรฐาน ไม่ต้อง `pip install` อะไรเพิ่ม

## วิธีใช้

1. ติดตั้งและเปิด Ollama
2. รันโปรแกรม: `python LocalAI.py` (หรือดับเบิลคลิก `LocalAI.exe`)
3. ยังไม่มีโมเดล → กด **⬇ ดาวน์โหลดโมเดล** ที่แถบด้านซ้าย

## ความสามารถ

- แชตแบบ streaming, ประวัติแชต (ค้นหา/เปลี่ยนชื่อ/ลบ), ส่งออก .md
- Markdown: หัวข้อ, ลิสต์, **ตาราง** (คัดลอกไปวางใน Excel ได้), โค้ดบล็อกพร้อม **ไฮไลต์สี**
- **แนบไฟล์** ข้อความ/โค้ด และ **รูป** (PNG/JPG/WEBP สำหรับโมเดลที่ดูรูปได้)
- **จัดการโมเดล**: ดาวน์โหลดพร้อมแถบความคืบหน้า, ดูข้อมูล (ขนาด, context, ความสามารถ), ลบ
- **บทบาท (System Prompt)** หลายชุด เลือกแยกตามแชตจากช่อง "บทบาท" ด้านบน
- โหมด Thinking, คัดลอก/วาง (คลิกขวา) ใช้ได้แม้เปิดแป้นภาษาไทย

## สร้างไฟล์ .exe (Windows)

**วิธีที่ 1 — ในเครื่องตัวเอง:** ดับเบิลคลิก `build_exe.bat` (ต้องมี Python)
ได้ไฟล์ที่ `dist\LocalAI.exe` เปิดได้เลยโดยไม่ต้องติดตั้ง Python

**วิธีที่ 2 — ให้ GitHub สร้างให้:** ทุกครั้งที่ push ไฟล์ในโฟลเดอร์นี้ GitHub Actions
จะสร้าง `.exe` ให้อัตโนมัติ ดาวน์โหลดได้จากแท็บ **Actions** → รายการล่าสุด → **Artifacts** → `LocalAI-windows`

> Windows Defender/SmartScreen อาจเตือนไฟล์ .exe ที่สร้างจาก PyInstaller เพราะไม่มีลายเซ็นดิจิทัล
> กด "More info" → "Run anyway" ได้

## ข้อมูลที่บันทึก

ประวัติแชตและการตั้งค่าอยู่ที่ `~/.local_ai_ollama_chat.json`
(รูปที่แนบจะถูกเก็บในไฟล์นี้ด้วย ถ้าแนบรูปบ่อยไฟล์จะใหญ่ขึ้น)
